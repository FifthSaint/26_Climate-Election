# 사라지지 않았지만, 중심에서 밀려났다
### 최근 3개 전국선거에서 기후·에너지 전환 담론의 변화: 빅카인즈 10,276건 텍스트 분석

> **Not Disappeared, but Pushed to the Periphery**  
> Shifting Climate and Energy Transition Discourse across Three Recent Korean National Elections:  
> A Text Analysis of 10,276 BigKinds Articles (2024–2026)

---

## 개요

본 연구는 제22대 국회의원선거(2024), 제21대 대통령선거(2025), 제9회 전국동시지방선거(2026)의 선거 전 30일간 보도를 대상으로, 기후·에너지 전환 어젠다가 어떻게 호명되고 변화했는지를 두 수준에서 분석한다.

**핵심 발견 — 성장과 포획의 역설**

선거 보도 중 기후 기사 비중은 3.7% → 4.2% → 4.6%로 **단조 증가**하고 있다. 그러나 바로 그 성장 속에서 '기후'는 독립 의제의 자리를 잃고 의미망 중심(1위 → 12위 → 33위)에서 밀려나며, 경제·산업·에너지원·AI·지역 개발 프레임으로 **질적으로 재맥락화**된다. 이 두 방향이 동시에 작동하는 이유는, 기후가 독립 의제로 커서가 아니라 고빈도 경제·에너지 프레임에 '올라타며' 가시성을 얻는 — **빌려온 현저성(borrowed salience)** — 때문일 수 있다.

**English abstract.**
Analyzing 10,276 Korean news articles collected from BigKinds across three consecutive national elections (2024 National Assembly, 2025 Presidential, 2026 Local), this study investigates how climate and energy-transition discourse is framed and repositioned. Results reveal a paradox: the quantitative share of climate-tagged election coverage rises monotonically (3.7 → 4.6%), yet within that coverage the climate node loses semantic centrality (rank 1 → 12 → 33 in co-occurrence networks) and is progressively absorbed into economic, industrial, nuclear-energy, and AI frames. Partisan framing diverges sharply—conservative outlets deploy an industry/cost lexicon (원전·전기료) while progressive outlets couple climate with justice issues (핵발전·차별금지)—and sentiment analysis confirms the opposition between a crisis-tone (progressive) and an opportunity-tone (economic press). Diachronic word embeddings track meaning-field migration: '기후' moves from mitigation/party-politics (2024) to adaptation/local-disaster (2026); '전환' loses its 'justice' neighbor and gains 'industrial structure'.

## 분석 파이프라인

### 구성도

```
빅카인즈 수집 (.xlsx × 3)
    │
    ├─ [양] 현저성 측정          ← 총기사 / 선거기사 / 기후기사 3단 비중
    │
    └─ [질] 기후 코퍼스 분석 (10,276건)
            ├─ 불용어·인물명 제거 / 명사 토큰화
            ├─ ① 프레임 어군 출현율  (이론 기반 어군 × 3 선거)
            ├─ ② LDA 토픽모델링     (K=12, 통합 코퍼스 학습 → 선거별 비중)
            ├─ ③ 의미망 중심성       (문서 공출현, 가중 연결중심성)
            ├─ ④ TF-IDF 변별어       (log-odds, DF≥25, 인물명 제거)
            ├─ ⑤ 정파성 변별어       (보수지 vs 진보지 log-odds)
            ├─ ⑥ 감성 분석           (KNU SentiLex, 명사 기반)
            └─ ⑦ 통시 임베딩         (Word2Vec 선거별 독립 학습 → 이웃 집합)
```

## 실행 방법

### 요구 사항

- Python 3.9 이상
- Jupyter Notebook 또는 JupyterLab

```bash
pip install pandas openpyxl gensim scikit-learn networkx numpy matplotlib
```

> `matplotlib`은 의미망 시각화에 필요하다. 한글 레이블 렌더링을 위해 NanumGothic 폰트 설치를 권장한다 (없으면 기본 폰트로 대체됨).

### 실행 순서

1. **데이터 수집**: 위 검색식으로 빅카인즈에서 각 선거별 기사를 수집해 `data/` 폴더에 저장한다.

2. **노트북 열기**:
   ```bash
   jupyter notebook klimakomm_analysis.ipynb
   ```

3. **`DATA_DIR` 설정**: 노트북 첫 번째 코드 셀에서 xlsx 파일 경로를 지정한다.
   ```python
   DATA_DIR = "./data"   # 기본값; 다른 경로라면 변경
   ```

4. **셀 순서 실행**: 셀을 위에서 아래로 순서대로 실행한다. 분석 항목별 소요 시간은 대략 다음과 같다.

   | 분석 | 소요 시간 (참고) |
   |------|----------------|
   | 데이터 로드·정제 | < 1분 |
   | 프레임 출현율·현저성 | < 1분 |
   | LDA 토픽모델링 (passes=8) | 1~3분 |
   | 의미망 중심성·군집 | 1~2분 |
   | 감성 분석 | 1~2분 |
   | Word2Vec × 3 (epochs=10) | 1~2분 |

### 재현성 주의사항

- LDA와 Word2Vec은 `random_state=42`·`seed=42`로 고정되어 있어 동일 데이터에서 동일 결과가 재현된다.
- 빅카인즈 색인은 시점에 따라 소폭 변동할 수 있다. 본 분석에서 사용한 수집 날짜는 **2026년 6월 초**이다.
- `분석제외 여부` 칼럼 처리 방식(결측치 = 유효 기사)이 버전 간 변경되면 유효 건수가 달라질 수 있다.

## 한계

1. **교집합 코퍼스** — 수집 단계에서 이미 기후 키워드로 필터링했으므로, 현저성 측정의 분자(기후기사)와 분모(선거기사)는 서로 다른 검색식으로 별도 수집한 수치다. 방향성은 견고하나 절대 비중은 검색식 정의에 따라 달라진다.
2. **감성 분석** — KNU 사전을 명사 토큰에만 적용하므로 부정어·서술어 극성이 누락된다. 매체 간 *상대 비교*에만 활용한다.
3. **Word2Vec 정렬 미적용** — 선거별 임베딩을 독립 학습했으므로 모델 간 코사인 유사도 직접 비교는 불가하다. 최근접 이웃 집합(set)의 질적 비교만 수행한다.
4. **토픽 수 K=12** — LDA 토픽 수는 탐색적으로 설정한 것이며, K 스윕을 통한 강건성 검증은 향후 과제다.
5. **'정의로운 전환' 측정 불가** — 해당 표현이 단일 명사로 추출되지 않아 구(句) 단위 검색이 별도로 필요하다.
